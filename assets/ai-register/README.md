# AI Asset Register

Create one record per generated asset containing:

- Asset ID and filename
- Page and section
- Communication purpose
- Prompt summary and reference inputs
- Generation and revision dates
- Approval status and approver
- Rights and disclosure note
- Alternative text
- Desktop, tablet, and mobile crop information
- Checks for misleading government, client, project, personnel, cultural, or technical details

Generated imagery must never be represented as proof of completed work.
