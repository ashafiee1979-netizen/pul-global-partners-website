# Session Close Checklist

- [ ] Re-read the latest user instruction.
- [ ] Update `STATUS.md` with completed work, blockers, unresolved questions, and the exact next action.
- [ ] Update backlog, decisions, risks, change log, and plan where facts changed.
- [ ] Record verification performed.
- [ ] Confirm no credentials, private exports, or sensitive data are staged.
- [ ] Run relevant checks.
- [ ] Commit completed work with a clear message.
- [ ] Report the commit, deliverables, decisions, and next-session start to the user.
