# ADR 002 AI Generated Imagery

- Status: Proposed
- Date: 2026-09-16

## Decision

Use a coordinated set of AI-generated conceptual images for selected page heroes and capability sections. Do not use generated images as evidence of completed work or imply government, client, personnel, or project affiliation.

## Controls

- Maintain an asset register with prompt summary, asset ID, date, approval, alt text, placement, rights note, and crop variants.
- Review every image for misleading details, cultural sensitivity, technical plausibility, embedded text, and brand consistency.
- Use real approved evidence on past-performance pages wherever available.
